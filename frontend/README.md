# Frontend

The frontend is organized as a React + TypeScript PWA designed for the SikhyaSetu offline-first hero flow. It keeps the learner experience deterministic, resilient, and capable of working without a live network connection.

## Key concerns

- local profiles and offline lesson execution
- teach-back recording and deferred grading
- sync queueing, dedupe, and retry behavior
- state isolation for shared-phone usage
- teacher brief and progress summaries derived from real learner evidence

## Scope

This frontend remains a proposal-aligned scaffold that preserves the required app shell, feature modules, offline state handling, and shared services needed to match the project brief.
